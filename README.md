# 엑셀 조사표 도우미

교육청 등에서 보내는 "빈칸을 채워야 하는" 엑셀 조사표를 업로드하면, 질문 형태로 하나씩 물어본 뒤 자동으로 엑셀 파일을 완성해서 다운로드해주는 도구입니다. 파일 처리는 전부 브라우저 안에서만 이루어지며, 어떤 데이터도 서버로 전송되지 않습니다.

## 엑셀 서식 규칙

- 질문 항목이 있는 행(헤더 행) 바로 아래에, 첫 칸이 `(예시`로 시작하는 행이 있어야 합니다.
- 예시 행은 1개여도 되고, 여러 개(예: 2~3개) 연속으로 있어도 됩니다.
- 예시 행들 바로 다음 행에 실제 답이 채워집니다.
- 헤더 행 자체는 파일 어디에 있어도 상관없습니다 (1행, 3행 등 무관).

## 로컬 실행

`index.html` 파일을 더블클릭해서 열면 바로 사용할 수 있습니다.
